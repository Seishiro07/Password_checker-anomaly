# Password_checker-anomaly
Password Strength Checker  password_checker.py takes a password with hidden typing and checks length, uppercase, lowercase, numbers and special characters.
It also flags common passwords, repeated characters and sequences like 1234.
It rates the password WEAK, MEDIUM or STRONG and gives improvement tips.
Test results: password came out WEAK, Hello123 MEDIUM and Tr0ub4dor&3xyz! STRONG.
          Run it with python password_checker.py.
